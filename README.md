This project analyzes publicly available TESS light curves of three well-known transiting exoplanets. For each star, it downloads the data from MAST, removes NaNs and outliers, normalizes and detrends the flux, and runs a blind Box Least Squares search to find the transit signal. It then folds the light curve on the recovered period, fits the transit shape, and converts the measured depth into a planet-to-star radius ratio. Results are compared against published values from the NASA Exoplanet Archive.
